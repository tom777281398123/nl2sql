## 1.中间件验证脚本

### 1.1 embeding

```sh
curl http://localhost:8081/embed -X POST -H "Content-Type: application/json" -d '{"inputs":"测试"}'
```

### 1.2 MySQL

```sh
# 方法1：使用 --protocol=TCP 参数（推荐）
mysql -h 127.0.0.1 -P 3306 -u root -p178121 --protocol=TCP -e "SHOW DATABASES;"

# 方法2：直接使用 127.0.0.1 而不是 localhost
mysql -h 127.0.0.1 -P 3306 -u root -p178121 -e "SHOW DATABASES;"
```
