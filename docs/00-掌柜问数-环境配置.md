## 一、前置准备（终端操作，全程不碰 PyCharm）

### 1.彻底清理旧环境

```sh
# 1. 退出所有 conda 环境
conda deactivate
# 确认退出（终端前无任何 (xxx) 标识）
echo $CONDA_DEFAULT_ENV

# 2. 进入项目目录
cd /Users/zhanghua05/project/py/storekeeper-nl2sql

# 3. 删除旧的 .venv 和缓存
rm -rf .venv
rm -rf __pycache__
rm -rf .pytest_cache
rm -rf .idea
```

## 二、用 uv 管理项目环境（核心步骤）

### 1. 安装 uv（如已安装可跳过）

```sh
# 安装 uv（官方脚本）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 重启终端或加载配置
source ~/.zshrc

# 验证安装
uv --version
```

### 2.安装指定版本 Python（推荐 3.11，解决 jieba 警告）

```sh
# 让 uv 帮你安装系统级 Python 3.11（和 conda 完全隔离）
uv python install 3.11

# 验证安装
uv python list
# 输出应包含：cpython-3.11.x
```

### 3.创建项目专属虚拟环境

```sh
# 创建 .venv 环境，强制使用 Python 3.11
uv venv .venv --python 3.11

# 激活环境（macOS/Linux）
source .venv/bin/activate

# 验证环境（终端前出现 (.venv) 标识）
which python
# 输出必须是：/Users/zhanghua05/project/py/storekeeper-nl2sql/.venv/bin/python
python --version
# 输出：Python 3.11.x
```

### 4.同步项目依赖（基于 pyproject.toml)

```sh
# 安装 pyproject.toml 中所有依赖
uv sync

# 验证依赖安装
uv pip list
# 确认 jieba==0.42.1 已安装（无警告版本）
```

## 三、PyCharm 绑定环境（关键：绕开 uv 专用选项）

```sh
1. 添加解释器（使用 Virtualenv 方式，100% 兼容）
打开 PyCharm → Settings → Project: storekeeper-nl2sql → Python Interpreter
点击右上角 + 号 → 新建解释器
左侧选择 Virtualenv Environment（不要选 uv！）
选择 Existing environment
在路径框中，直接粘贴下面的完整路径：
	/Users/zhanghua05/project/py/storekeeper-nl2sql/.venv/bin/python
点击 OK 保存

2. 验证 PyCharm 配置
右下角状态栏应显示 Python 3.11 (.venv)
  which python
  # 输出应与上面路径一致
  uv pip show jieba
  # 确认版本为 0.42.1

```
