# 掌柜问数 — 环境配置（uv 版）

> 本工程以 [`uv`](https://docs.astral.sh/uv/) 作为唯一的 Python 包/环境管理器，所有依赖都由 `pyproject.toml` 与 `uv.lock` 锁定。请按本文档操作，不要再使用 `conda` / `pip install` / `virtualenv` 等其他方式管理依赖。

## 一、前置准备

### 1. 退出其它 Python 环境

```sh
# 如果之前在 conda 中，先退出
conda deactivate 2>/dev/null || true

# 确认终端提示符前没有 (xxx) 标识
echo "CONDA_DEFAULT_ENV=${CONDA_DEFAULT_ENV:-<none>}"
```

### 2. 进入项目目录

```sh
# 使用你本地的实际路径，例如：
cd <你的本地路径>/storekeeper-nl2sql

# 确认当前目录包含 pyproject.toml
ls pyproject.toml uv.lock
```

### 3.（可选）清理历史虚拟环境与缓存

```sh
rm -rf .venv __pycache__ .pytest_cache
```

> `.idea/` 是 PyCharm 的工程文件，**不建议**全部删除（删除后 Run Configuration 等需要重新配置）。`.gitignore` 已忽略它，本地保留即可。

## 二、安装 uv

```sh
# 官方安装脚本（macOS / Linux）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 让 PATH 立即生效（zsh）
source ~/.zshrc

# 验证
uv --version
```

> Windows 用户请使用 PowerShell：
> `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

## 三、创建项目环境并安装依赖

`pyproject.toml` 已声明 `requires-python = ">=3.11"`，`uv` 会自动按需下载合适的 CPython。一条命令即可完成 **解释器安装 + venv 创建 + 依赖同步**：

```sh
uv sync
```

执行完成后会在项目根目录生成 `.venv/`，并按 `uv.lock` 还原所有依赖（包括 `jieba==0.42.1`、`langchain==1.2.7`、`langgraph==1.0.7` 等）。

如果需要显式指定 Python 版本（例如固定 3.11）：

```sh
uv python install 3.11
uv venv --python 3.11
uv sync
```

### 验证环境

```sh
# 激活后再验证（macOS / Linux）
source .venv/bin/activate

which python   # 应指向 <项目目录>/.venv/bin/python
python --version   # Python 3.11.x

uv pip list | grep -E "jieba|langgraph|fastapi"
```

> 之后所有命令都推荐用 `uv run <cmd>` 形式调用，无需显式 `activate`。例如 `uv run python -m backend.main`。

## 四、配置项目环境变量

项目根目录的 `.env` 在运行时被读取（见 `backend/app/conf/`），默认内容如下：

```dotenv
META_KNOWLEDGE_CONFIG=backend/conf/meta_config.yaml
SYS_ISCLEAN_CONFIG=true
```

- `META_KNOWLEDGE_CONFIG`：元数据知识库构建配置文件路径。
- `SYS_ISCLEAN_CONFIG`：是否在启动时清空并重建知识库（首次启动建议为 `true`，之后可改为 `false` 避免每次启动都重新构建索引）。

> 中间件相关的密码/库名等环境变量在 `docker/.env.debug` 中维护，由 `docker-compose` 读取，不需要在项目 `.env` 中重复。

## 五、PyCharm 绑定 .venv 解释器

uv 创建的 `.venv` 与标准 venv 完全兼容，PyCharm 任一方式都可：

**方式 A（推荐，最稳）：以 “已存在的 Virtualenv” 绑定**

1. `Settings` → `Project: storekeeper-nl2sql` → `Python Interpreter`
2. 右上角 `Add Interpreter` → `Add Local Interpreter` → `Virtualenv Environment`
3. 选择 `Existing environment`，路径填：
   ```
   <你的本地路径>/storekeeper-nl2sql/.venv/bin/python
   ```
4. 确认状态栏显示 `Python 3.11 (.venv)`。

**方式 B：使用 PyCharm 自带的 uv 集成（2024.1+）**

`Add Interpreter` → `uv` → 选择项目目录即可，PyCharm 会自动调用 `uv sync`。

两种方式效果一致，团队成员保持一致即可。

## 六、常见命令速查

```sh
# 安装/同步依赖（含开发依赖）
uv sync

# 仅安装运行依赖（生产环境）
uv sync --no-dev

# 新增一个依赖
uv add <package>

# 移除依赖
uv remove <package>

# 升级锁文件
uv lock --upgrade

# 在 venv 内运行命令（无需 activate）
uv run python -m backend.main
uv run pytest
```
