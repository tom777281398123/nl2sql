# 掌柜问数 · 课程教案（9 讲）

> 本目录是《掌柜问数 NL2SQL 实训课》的完整教案，面向 **大数据专业大四学生**。
> 总体大纲见 `../05-掌柜问数-课程设计大纲.md`；本目录把大纲的 9 讲逐一展开为可授课的教案。
>
> 每一讲都包含：**教学目标 → 教学重点 → 教学难点 → 原理精讲 → 代码精读（引用项目真实代码）→ 环境与上机 → 常见坑 → 扩展练习（基础/进阶/挑战）→ 思考题**。
> 设计意图：学生按教案学完，不仅能跑通系统，更能理解“为什么这样设计”，并基于本项目发挥能动性，做出更优秀的扩展。

## 如何使用本教案

- **教师**：每讲按“原理 → 代码精读 → 上机 → 扩展”推进，理论 2 学时 + 上机 2 学时。
- **学生**：先通读“原理精讲”，对照“代码精读”打开项目真实文件逐行看，再独立完成“上机”和“扩展练习”。
- **代码约定**：教案中代码均**节选自项目真实文件**，并标注路径如 `backend/app/agent/nodes/recall_column.py`。请务必打开真实文件对照，教案不替代源码。
- **环境约定**：统一用 `./run.sh` 起停（见项目根 `run.sh` 与 `CLAUDE.md`）。

## 贯穿全课的“能动性”主线

每讲扩展练习的“挑战级”都指向**课程设计大作业**（第 9 讲）的 5 个方向：结果可视化、多轮对话、SQL 安全护栏、召回评测、知识库扩域。建议学生从第 1 讲就选定方向，边学边攒素材，最终交付一个真正属于自己的增强版掌柜问数。
